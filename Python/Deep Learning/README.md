# Deep Learning School Projects

This folder contains several deep learning projects created as part of my coursework in deep learning and artificial intelligence. Each project focuses on a specific concept, such as neural network architectures, training strategies, model robustness, and applied computer vision.

---

## About the Projects

The purpose of these deep learning projects was to learn and demonstrate core concepts in deep learning, including:

- Designing and training neural networks for image-based tasks  
- Using convolutional neural networks (CNNs) for feature extraction and classification  
- Applying transfer learning with pre-trained models  
- Evaluating model performance, generalization, and robustness  
- Exploring adversarial attacks and defensive strategies in deep learning systems  
- Applying theoretical knowledge to practical, experiment-driven implementations in Python  

Each project focuses on a specific topic covered in coursework, providing hands-on experience with neural network behavior, model training, evaluation, and real-world deep learning challenges.
