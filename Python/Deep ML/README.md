# Deep Learning School Projects

This folder contains deep learning projects developed as part of coursework in deep learning and artificial intelligence. The projects focus on neural network training, model comparison, image classification, and time-series anomaly detection.

---

## About the Projects

The deep learning projects in this folder explore core concepts including:

- Convolutional neural networks (CNNs) and image classification
- Transfer learning with pre-trained models
- Model performance, generalization, and overfitting
- Time-series anomaly detection with LSTM autoencoders
- Reconstruction-error-based anomaly detection
- Baseline comparison with traditional machine learning models
- Evaluation using accuracy, precision, recall, F1-score, and ROC-AUC

---

## Included Projects

- **CIFAR-100 Deep Learning Model Benchmark**  
  Compared a custom CNN with ResNet-50, VGG-19, DenseNet-121, and EfficientNet-B0 for image classification.

- **Spacecraft Telemetry Anomaly Detection**  
  Used LSTM autoencoders and a K-Means baseline to detect anomalies in NASA SMAP/MSL time-series data.
