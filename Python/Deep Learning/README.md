# Deep Learning School Projects

This folder contains deep learning projects developed as part of coursework in deep learning and artificial intelligence. The projects focus on neural network training, robustness, and distributed learning under realistic conditions.

---

## About the Projects

The deep learning projects in this folder explore core concepts including:

- Convolutional neural networks (CNNs) and image-based learning  
- Transfer learning with pre-trained models  
- Model performance, generalization, and robustness  
- Adversarial and security-related challenges in deep learning  
- Federated learning under IID and non-IID data distributions
